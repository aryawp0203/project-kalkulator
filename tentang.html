Kalkulator Modern

Kalkulator berbasis web yang responsif dan mudah digunakan untuk kebutuhan perhitungan sehari-hari. Dibangun dengan HTML, CSS, dan JavaScript tanpa framework tambahan.

Fitur utama

Perhitungan lengkap

Penjumlahan, pengurangan, perkalian, pembagian, persentase kalkulatif (misalnya 200 + 10% = 220), dan pengubahan tanda bilangan. Pembagian dengan nol ditangani, dan hasil dihitung dengan presisi desimal yang lebih baik.

Tampilan nyaman

Pilih mode gelap atau terang. Tampilan responsif, format angka Indonesia menggunakan titik untuk ribuan dan koma untuk desimal, serta ukuran angka menyesuaikan panjang hasil.

Riwayat perhitungan

Riwayat tersimpan di browser, dapat digunakan kembali, dan bisa dihapus kapan saja.

Dukungan keyboard

Masukkan angka dengan 0–9 dan operator +, -, *, atau /. Gunakan Enter atau = untuk menghitung, % untuk persentase, Backspace untuk menghapus, Escape untuk membersihkan, dan H untuk membuka riwayat.

Cara menjalankan

Jalankan melalui Laragon atau web server lokal, lalu buka http://localhost/pwd-2026/project-kalkulator/. Anda juga dapat membuka berkas index.html langsung di browser.
